## 怎么开始玩

### 1. 安装 Python

去 [python.org](https://www.python.org/downloads/) 下载安装 **Python 3.10 或更高版本**。

安装时记得勾选 ✅ `Add Python to PATH`

### 2. 下载游戏

```bash
git clone https://github.com/Haihaihai088/xianjie.git
cd xianjie
```

或者直接点 GitHub 页面的绿色 `<> Code` 按钮 → `Download ZIP` → 解压。

### 3. 安装依赖

```bash
pip install pygame
```

### 4. 启动

```bash
python main.py
```

Windows 用户也可以直接双击 `run_game.bat`。

## 怎么玩

打开游戏 → 按回车 → **开始渡劫**

| 操作 | 键 |
|------|-----|
| 上下左右 | 菜单导航 |
| 回车 / 空格 | 确认 |
| 鼠标点击 | 选卡牌 / 菜单 |
| ESC | 战斗中暂停 |

### 战斗规则

1. 每轮出现 **两张卡牌**，选一张
2. 卡牌加三种属性：`灵力` `根骨` `身法`
3. 属性值达到目标线 → **渡劫成功**
4. 连续选同风格卡牌 → **连击加成**
5. 越快通关，**天赋评级越高**

## FAQ

**Q: 卡住了怎么办？**
ESC 暂停 → 重开本关 或 返回菜单

**Q: 能存档吗？**
通关自动存档。下次打开菜单有"继续游戏"

**Q: 画面太暗？**
游戏偏暗黑仙侠风格，是设计意图

**Q: 报错了？**
先跑 `diagnose.bat` 检查环境，看 `launch_log.txt`
